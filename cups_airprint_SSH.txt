二、安装 Docker 前准备
1. 安装 Docker
2.确认 dockerd：
/etc/init.d/dockerd status

三、非常重要：设置 Docker 数据目录问题

ImmortalWrt 默认 Docker 可能使用：
/var/lib/docker

甚至：
/tmp/lib/docker

如果在 tmpfs：
重启后：
镜像消失
容器消失

1. 修改 Docker 数据目录

创建配置：
mkdir -p /etc/docker

编辑：
cat > /etc/docker/daemon.json <<'EOF'
{
  "data-root": "/opt/docker",
  "ipv6": false,
  "ip6tables": false
}
EOF
2. 清理旧 Docker 临时配置

停止 Docker：

/etc/init.d/dockerd stop

如果进程没有退出：
查看：

ps | grep dockerd

强制结束：

kill -9 PID

例如：

kill -9 2366

删除临时配置：

rm -rf /tmp/dockerd

3. 启动 Docker

/etc/init.d/dockerd start

确认：

docker info | grep "Docker Root Dir"

正确结果：

Docker Root Dir: /opt/docker

四、测试 Docker 是否正常
测试拉取镜像：
docker pull hello-world

运行：
docker run hello-world

确认：
docker images

如果docker出现镜像拉去不了，可能有ipv6的问题，按照以下内容处理

# 1. 关闭 IPv6（如果 Docker 又出现 IPv6 网络问题）
sysctl -w net.ipv6.conf.all.disable_ipv6=1
sysctl -w net.ipv6.conf.default.disable_ipv6=1

# 2. Docker 禁用 IPv6
cat > /etc/docker/daemon.json <<'EOF'
{
  "ipv6": false,
  "ip6tables": false
}
EOF

# 3. 重启 Docker
/etc/init.d/dockerd restart
sleep 5


# 4. 下载 AirPrint CUPS 镜像
docker pull chuckcharlie/cups-avahi-airprint:latest

五、创建 CUPS 数据目录

为了以后删除容器不丢配置：

mkdir -p /opt/cups/config
mkdir -p /opt/cups/log
mkdir -p /opt/cups/spool

目录作用：
/opt/cups/config
    CUPS配置

/opt/cups/log
    日志

/opt/cups/spool
    打印任务缓存
    
六、确认 USB 打印机已连接
执行：（应该在第七步后执行测试该命令）
docker exec cups lsusb

这次 Canon G3000 的关键 USB ID 是：
04a9:1794


七、创建 CUPS + AirPrint 容器

删除旧容器：

docker rm -f cups

创建：

docker run -d \
--name cups \
--restart always \
--network host \
--privileged \
-e CUPSADMIN=admin \
-e CUPSPASSWORD=admin \
-v /opt/cups/config:/etc/cups \
-v /opt/cups/log:/var/log/cups \
-v /opt/cups/spool:/var/spool/cups \
--device /dev/bus/usb:/dev/bus/usb \
chuckcharlie/cups-avahi-airprint:latest

参数说明：

参数	作用
--restart always	重启自动启动
--network host	使用宿主网络，AirPrint需要
--privileged	允许访问USB
-v config	保存CUPS配置
-v log	保存日志
-v spool	保存打印任务
--device USB	映射打印机
八、检查 CUPS 是否运行

查看容器：
docker ps

正常：
cups   Up

查看日志：
docker logs cups --tail 50

正常看到：
Server startup complete
exec /usr/sbin/cupsd -f

如果密码有问题，登录192.168.5.1：631 Administration有问题，则按照下述命令重置密码，
docker exec cups sh -c 'echo "admin:admin" | chpasswd'
如果防火墙有问题，按照下面的设置

我们之前配置了 LAN → CUPS 631：

uci add firewall rule
uci set firewall.@rule[-1].name='CUPS'
uci set firewall.@rule[-1].src='lan'
uci set firewall.@rule[-1].target='ACCEPT'
uci set firewall.@rule[-1].proto='tcp'
uci set firewall.@rule[-1].dest_port='631'
uci commit firewall

mDNS：

uci add firewall rule
uci set firewall.@rule[-1].name='mDNS'
uci set firewall.@rule[-1].src='lan'
uci set firewall.@rule[-1].target='ACCEPT'
uci set firewall.@rule[-1].proto='udp'
uci set firewall.@rule[-1].dest_port='5353'
uci commit firewall

最后：

/etc/init.d/firewall restart

原因：

Docker Root Dir: /var/lib/docker

实际：

/tmp/lib/docker

解决：

/opt/docker

curl -I https://registry-1.docker.io/v2/

HTTP/2 401

/opt/cups/config

cp: can't stat /etc/cups/cupsd.conf

打印机自动关机后，再开机，需要重启docker容器才行，具体步骤如下：
1. 手动创建文件夹
mkdir -p /etc/hotplug.d/usb/

2.脚本
cat <<EOF > /etc/hotplug.d/usb/10-printer-restart
#!/bin/sh
if [ "\$ACTION" = "add" ] && [ "\$PRODUCT" = "4a9/1794/306" ]; then
    logger "检测到打印机上线 (v306)，正在重启 CUPS 容器..."
    docker restart cups
fi
EOF
3. 赋予执行权限
chmod +x /etc/hotplug.d/usb/10-printer-restart
